# HTML Quick Reference — Course 55320A

## Skeleton
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Page Title</title>
</head>
<body>...</body>
</html>

## Core elements
h1-h6, p, br, hr, strong, em, blockquote, q, cite, pre, code, div, span
a (href, target, rel), img (src, alt, width, height), figure, figcaption
ul/ol/li, dl/dt/dd

## Special characters
&amp; &lt; &gt; &copy; &nbsp; &deg;
