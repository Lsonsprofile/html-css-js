# Programming with HTML, CSS and JavaScript

Interactive learning platform covering all 11 modules from Course 55320A.

## Run locally

```bash
node server.js
```

Open **http://127.0.0.1:3000**

## Features

- Polished dashboard UI with progress tracking
- Full curriculum: HTML → CSS → JavaScript basics
- Live coding playground (HTML / CSS / JS)
- SVG diagrams and interactive demos
- Quizzes, exercises, and guided projects
- Responsive design (mobile, tablet, desktop)

## Structure

```
server.js                 # Node HTTP server + API
content/modules.json      # Course structure
public/
  index.html
  css/styles.css
  js/app.js
  js/content-data.js      # Lesson content
  js/visuals.js           # Diagrams & interactive tools
```
